## Status: COMPLETED

## Current Task
Two major infrastructure changes deployed in this session:
1. Migrated HTML publishing from GitHub Gist to S3
2. Added custom domain nowigetit.us via CloudFront + ACM + Route 53

## Why (Context)
The app was publishing generated HTML pages as GitHub Gists viewed via gistpreview.github.io — an unnecessary external dependency since the share-it-amroja S3 bucket already supports static website hosting. Removing the GitHub dependency also eliminated the GITHUB_TOKEN requirement and the requests library.

After the S3 migration, the user purchased nowigetit.us and configured a Route 53 hosted zone. We added CloudFront with an ACM TLS certificate to serve the frontend at https://nowigetit.us with www redirect.

## Decisions Made
- S3 publishing uses uppercase path `NOWIGETIT/{job_id}.html` (distinct from lowercase `nowigetit/` used for PDFs)
- CloudFront uses S3 website endpoint as custom HTTP origin (no OAC) — avoids changing the S3 bucket configuration
- ACM cert provisioned in deploy.sh (not CloudFormation) to avoid stack creation blocking on DNS validation
- www redirect handled by CloudFront Function (no extra S3 bucket needed)
- API stays on raw API Gateway URL (not custom domain) since it's only referenced in config.js
