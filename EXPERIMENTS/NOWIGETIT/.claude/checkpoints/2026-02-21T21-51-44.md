## Current Task
Added progress stages to processing UX and redesigned the frontend with a premium "Scholarly Luxe" aesthetic.

## Why (Context)
Processing takes 3-5 minutes and the user saw only a generic "Generating..." message. We added granular progress tracking (uploading → reading → generating → publishing) and redesigned the frontend to be more visually inviting.

## Decisions Made
- **Progress stages stored in DynamoDB**: Added `progress_stage` field to job records, updated at each processing step (uploading, reading, generating, publishing, complete, error)
- **Background thread for local dev**: Moved processing from synchronous request handler to `threading.Thread(daemon=True)` so polling works during local development
- **Frontend redesign direction**: "Scholarly Luxe" — DM Serif Display + DM Sans fonts, warm amber/gold accent palette (#e8a838), glass-morphism cards, animated ambient glow, grain texture overlay, connector lines in stepper, staggered entrance animations
