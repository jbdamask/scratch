How it works

  1. Enter a public GitHub repository URL (e.g., https://github.com/fastapi/fastapi)
  2. Click "Analyze Repository" to fetch and analyze the codebase
  3. Claude will examine the code structure and generate relevant Mermaid diagrams
  4. Browse the generated diagrams in the carousel view
  5. Click any diagram to expand and view details, with options to copy or download
