About Company Shorts

A single-page web tool that generates research summaries about companies using the Perplexity AI API.

Purpose

Enter a company URL and get a detailed research report including:

  • Business Model and Services
  • Company Growth
  • Corporate Partnerships and Notable Customers
  • Market Position
  • References

Setup

  1. Click Settings to expand the configuration panel
  2. Enter your Perplexity API key and click the save icon
  3. Select your preferred report type:
    • Short - Fast, basic research
    • Comprehensive - Most detailed analysis

Getting a Perplexity API Key

  1. Go to perplexity.ai/account/api
  2. Create an API key
  3. Copy and paste it into the Settings panel

Usage

  1. Enter a company URL (e.g., anthropic.com)
  2. Click Research
  3. Wait for the report to generate
  4. Use Copy or Save to export the report
